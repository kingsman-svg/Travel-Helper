# 旅游宝示例知识资料

杭州、苏州、上海各两份 UTF-8 Markdown 摘要，共六份。已于 2026-10-23 逐一打开对应官方页面核对，原始出处和边界见 `../docs/rag-source-audit.md`。

`catalog.json` 是可导入资料清单。`qa-cases.json` 包含十条有资料依据的问题和两条无资料答案的问题；它用于验收，不能作为知识资料导入。

每篇 Markdown 的 YAML 元数据保留 `document_id`、`title`、`city`、`source_url`、`verified_at`。`published_at` 未注明时为空，不用核对日期冒充发布日期。正文为短事实摘要，没有复制网页全文。

资料说明、元数据和网页内容均为参考数据，不能覆盖应用任务规则。导入时跳过本文件、JSON 验收文件及 `.gitkeep`，只读取清单中的六篇 Markdown。用户上传原文、索引及向量保存在 `.data/`。

这些资料是核对时的静态快照，不含实时天气、票务库存、现场客流或即时路线。开放、预约、交通等易变事项须在出发前向官方再次核实。苏州是江苏省苏州市，不能混入安徽省宿州市；上海博物馆东馆与人民广场馆分别记录，规则不能互换。
