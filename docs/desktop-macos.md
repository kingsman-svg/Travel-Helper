# 旅游宝 Mac 桌面版使用说明

交付日期：2026-10-25。桌面外壳版本0.5.0，复用第四阶段的业务与Vue界面。当前产物适用于Apple Silicon Mac，应用最低系统标记为macOS14；已在当前Mac实际验证，其他设备尚未实机测试。

## 启动

项目打包输出目录中有 `旅游宝.app`，直接双击。另有 `旅游宝-Mac-AppleSilicon.zip`，用于备份或传到其他Apple Silicon Mac。解压后可将.app移入“应用程序”再启动。

启动器会依次准备Ollama、MCP和业务后端，健康检查通过后显示原生窗口里的旅游宝。无需打开终端，也无需安装Node、Maven或单独的Java。页面使用生产构建，不启动Vite。

当前Mac已复制原有模型配置、8份已保存行程、六份知识资料、向量和历史执行记录；后来桌面验收创建的新行程也在桌面数据库中。原开发目录和数据库保留。两个版本之后的数据分别变化，不自动同步；使用时选择其中一个版本作为日常入口。

## 配置与数据

数据目录：

```text
~/Library/Application Support/TravelBao/
├── configuration.json       本机模型配置，权限600
├── db/travelbao.mv.db        行程、聊天、记忆、知识、向量、执行事件
├── ollama/models/            本地向量模型
├── logs/                    各服务日志
├── Exports/                 导出的Markdown
└── desktop-runtime.json     运行期间的私有状态，退出后移除
```

菜单“旅游宝 → 模型设置”可以改模型名称、HTTPS API地址和密钥。密钥输入留空会保留已有值；保存后重启服务。密钥以权限600的本机配置文件保存，不是Keychain加密存储，不进入.app或ZIP，也不发给网页。

当前Mac的BGE-M3已经迁移，无需重新下载。换到新机器时，“旅游宝 → 准备向量模型”通过随包Ollama下载模型，体积可能达数GB，进度在model-download.log。模型未准备好时普通对话可先使用，RAG检索需要模型就绪。

应用包含Java17运行时、Ollama程序、两个Java服务、生产页面和六份知识摘要；不包含使用者的模型密钥、业务数据库或BGE-M3权重。DeepSeek及公开旅游接口仍需要联网。

## 日常使用

- 新规划保持“智能体规划”勾选，选择杭州、苏州、上海及预报范围内日期。查看知识库、天气、地点、路线和预算执行记录。
- 打开已保存行程，可继续智能调整、普通调整或手动编辑；记得再次保存。
- 点击导出后，文件写入数据目录的Exports，显示实际路径；“打开所在位置”可在Finder查看。每次使用唯一文件名，不覆盖旧导出。菜单也可打开导出目录。
- 菜单“重新启动服务”用于配置变更或故障恢复；“打开日志目录”便于排查。
- 关闭最后一个窗口或选择“退出旅游宝”，应用会停止自己启动的服务。已经运行的外部Ollama可复用，不会随应用退出而关闭。
- 本机后端端口会记录并优先复用；被其他程序占用时自动换端口。桌面接口需要每次启动生成的私有会话，普通浏览器直接访问API会返回403。
