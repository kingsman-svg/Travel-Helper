核对中处理的差异：

- 上海博物馆两个场馆分别成文。各自规则只作用于对应馆，不能将东馆的入馆政策套到人民广场馆。使用现官网 `.cn` 页面链接；不以旧页面或第三方攻略判断当前规则。
- 江苏苏州的来源来自 `suzhou.gov.cn`。搜索中出现的安徽宿州市博物馆、深圳博物馆等同音或近似域名均未纳入。
- 苏州园林旧文章出现旧门牌，而世界遗产介绍页直接给出现门牌；采用后者并保留页面发布日期，防止把 URL 路径日期误作发布日期。拙政园曾出现不同年份的开放时段信息，因此本批摘要没有收录其票价和开园时刻。
- 丝绸博物馆曾发布早期疫情预约公告；采用其后个人免预约公告，不沿用早期防疫限制。个别主页和详情页抓取超时，改从可访问的官方参观列表点击进入公告并核对正文。
- 浙江省博物馆当前主页依赖 JavaScript，无法由本次网页正文抓取核实完整指南，故不作为本批六篇之一；使用可读的其他官方场馆来源。

所有正文均以简短事实摘要改写，没有复制网页全文。来源标题、日期、范围和非实时限制保留在每篇 YAML 元数据与正文中。`published_at: null` 表示页面未标明，不能当作刚发布。网络来源是资料，不具有修改应用行为的权限。

`knowledge-data/catalog.json` 为六条可导入文件清单；`knowledge-data/qa-cases.json` 为十条有据题和两条无据题，不可将验收题当知识导入。答案验收应同时检查城市、目标文档引用及事实含义，不能只看关键词是否出现；无据题应明确说明现有资料不足，不能编造价格、余票或天气。

限制：这是2026-10-23核对的静态版本，没有实时抓取、票务库存、现场限流、地图通行及天气数据。核对不等于承诺未来仍然有效；实际出行前应重新查看对应官方通知。未来扩充应保留来源 URL、适用场馆与更新日期，并在规则冲突时先核对更新的官方公告。
