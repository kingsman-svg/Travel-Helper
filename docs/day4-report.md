# 第四天：真实 MCP 工具与 ReAct

完成日期：2026-10-24（Asia/Shanghai），版本0.4。第四阶段已完成；第五阶段的Mac桌面包与最终彩排尚未开始。

## 可以直接操作的功能

- 需求表默认启用“智能体规划”；模型自主查询知识、天气、地点和路线，再提交完整行程做预算/日程校验。
- 已有行程可选“智能调整”，保留权威城市、日期、人数、预算和包含项。明确的每日/全天步行上限、单日少走路及其他日期保护由后端校验。
- 执行面板展示实际工具名、参数、JSON结果、状态、耗时、提供方、查询/数据获取时间及知识来源。
- 最多6轮模型决策、10次工具、90秒；支持停止、故障终止与重启后记录恢复。只有合格行程写入草稿；保存和Markdown导出保留来源及执行ID。
- 原有普通规划、流式咨询、知识问答、编辑、保存、导出仍可使用。

三个MCP工具对接 Open-Meteo、Photon、FOSSGIS Valhalla，覆盖杭州、苏州、上海，不需要额外地图密钥。高德尚未接入。天气支持今天至未来15天；道路路线无实时路况、公共交通班次或实时票价。公开服务可能不可用，所有失败保留实际状态。详见 [数据提供方](tourism-providers.md)。

## 本轮修复与实现边界

1. 将“全天步行不超过N分钟”加入已有每日上限识别，测试覆盖该措辞；真实72分钟方案被拒后修复为58分钟。
2. 最终预算工具校验成功后直接完成，避免第六轮有效提交仍需要第七轮确认。自动测试专门覆盖第六轮直接完成。
3. 已解决的内部格式/预算校验错误不再作为待确认事项遗留；上游仍不可用的工具会保留警告。
4. 取消后旧工作线程不能迟到提交或释放新任务的会话锁。全局超时独立触发，执行事件持久化；服务启动将残留RUNNING标为INTERRUPTED。
5. 中断前自行创建的验收示例曾有73分钟旧草稿。只修正了这一份本轮验收数据，并记录为手动编辑；最终正式脚本使用全新会话重新验证，没有沿用修正数据冒充生成成功。

智能体按Spring AI 1.1.8关闭自动工具执行，由AgentService维护唯一循环。模型消息与ToolResponseMessage按真实协议衔接。普通聊天通过MessageChatMemoryAdvisor载入历史；智能体读取同一JDBC记忆仓库并只保存成功请求/摘要，RAG Advisor注入本次实际命中。行动摘要是应用展示信息，不展示模型内部思维链。

预算由BigDecimal确定性计算；行程文字、费用与活动步行本身仍为模型估计，文字摘要偶尔会与日程逐项合计略有差异，应以页面校验合计为准。真实工具来源只证明本次查询结果，不能证明场馆当日开放、无障碍可达或存在票务库存。全国覆盖、支付、账号、预订和安装包不属于本阶段。
